# GuidelineGo 🩺 

### مساعد ذكي تفاعلي للصيادلة في الأردن

**GuidelineGo** هو تطبيق ويب مصمم لتمكين الصيادلة من اتخاذ قرارات سريرية دقيقة وسريعة بناءً على البروتوكولات الطبية العالمية والمحلية، باستخدام تقنيات الذكاء الاصطناعي (Prompt Engineering).

## المميزات:
- **نظام شجرة القرارات:** يوجه الصيدلاني خطوة بخطوة من خلال أسئلة بسيطة.
- **توطين المحتوى:** يقترح البدائل التجارية المتوفرة في السوق الأردني (مثل منتجات شركة الحكمة، JPM، وغيرها).
- **سهولة الاستخدام:** واجهة محادثة بسيطة تناسب ضغط العمل داخل الصيدلية.

## التقنيات المستخدمة:
- **Frontend:** HTML5, CSS3, JavaScript.
- **AI Logic:** OpenAI GPT-3.5 API (Prompt Engineering).

## طريقة التشغيل:
1. قم بتحميل الملفات.
2. افتح ملف `index.html` في أي متصفح.
3. ابدأ المحادثة بإدخال حالة المريض.
